# CV: Skills, Experience and Courses

## Technical skills

The programming languages and tools I actually use day to day are:

- **HTML** for page structure.
- **Tailwind CSS** for styling. I like utility classes because I can build a clean, responsive layout quickly without writing long separate CSS files.
- **JavaScript** for front-end logic and interactivity.
- **Node.js** and **Express** for the back end, for building servers, routes and APIs.

So I work on both the front end and the back end. I would say my strongest area is web development with this stack: HTML, Tailwind CSS and JavaScript on the front end, and Node.js with Express on the back end.

Through my projects I have also worked with:

- **React.js** for building component-based user interfaces.
- **Supabase** as a database and backend service.
- **GitHub** for version control and keeping my projects online.
- **Python**, including **FastAPI** for a simulator project, and **YOLO (Ultralytics)** with **ONNX** for a computer vision project.
- **React Native** for a mobile app concept.
- **Antigravity**, an AI-assisted coding tool, which I used while building my LoopTech360 Support project.
- **VS Code** as my editor.

My preferred stack overall is React, Node.js, Supabase and VS Code.
